*[atom]: A chat agent declared with chatomon: instructions, knowledge and a connector, surrounded by input and output orbitals.
*[atoms]: Chat agents declared with chatomon: instructions, knowledge and a connector, surrounded by input and output orbitals.
*[nucleus]: The native agent an atom builds: the model with the atom's instructions and knowledge.
*[orbital]: A check that runs on a user message before the nucleus sees it, or on a reply before the user sees it.
*[orbitals]: Checks that run on a user message before the nucleus sees it, or on a reply before the user sees it.
*[verdict]: What an orbital returns: allow, block or respond.
*[verdicts]: What orbitals return: allow, block or respond.
*[guidance]: An instruction an orbital gives the model for one model call; it is never stored in the conversation history.
*[turn]: One user message and the reply the user receives, with every orbital check and regeneration in between.
*[turns]: User messages and the replies the user receives, with every orbital check and regeneration in between.
