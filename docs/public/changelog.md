# Changelog

## Overview

The release notes of every chatomon version are published as
[GitHub Releases](https://github.com/zazza123/chatomon/releases). Each merged
pull request is one line, grouped into breaking changes, features, fixes,
security, documentation and maintenance.

## Versioning

chatomon follows [Semantic Versioning](https://semver.org/). While the version
is `0.x`, a backwards-incompatible change bumps the minor version (`0.1.x` →
`0.2.0`) and every other change bumps the patch version. Release candidates
such as `0.2.0rc1` are published to PyPI as pre-releases; pip installs them
only when asked explicitly (`pip install --pre chatomon`).

Only the latest release receives fixes — see the
[security policy](https://github.com/zazza123/chatomon/blob/main/SECURITY.md).
